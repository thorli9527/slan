我的网络

把自己的设备放进一个安全网络

网络用来组织你的电脑、手机和服务。进入网络后，可以添加设备、配置内网域名，并设置哪些设备能访问哪些端口。

1添加设备把可见设备加入当前网络
2设置域名用 mac.home.lan 访问设备端口
3配置访问按入站/出站规则控制访问
